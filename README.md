# Command Center

A personal command-line activity tracker built with Python. Command Center brings guitar practice, debate preparation and fitness tracking together in one application.

I built this project independently to organise my daily activities, record progress and review previous entries.

## Features

### Guitar Tracking
- Log songs you practise.
- Record practice time.
- Track techniques practised.
- Record dates.

### Debate Tracking
- Log debate motions.
- Record preparation or practice time.
- Rate personal difficulty on a scale of 1 to 10.
- Review previous debate entries.

### Fitness Tracking
Supports two types of fitness activities:

**Circuit Training**
- Record exercises.
- Track repetitions and sets.
- Rate exercise difficulty from 1 to 10.

**Running**
- Record running pace.
- Track distance and time.
- Review previous running entries.

### Centralised Menu
- Navigate between guitar, debate and fitness tracking.
- Access saved records through the statistics menu.
- Handle invalid inputs with exception handling and input validation.

## Technologies Used

- Python
- CSV for persistent data storage
- PyInstaller for Windows executable packaging

The application uses Python's built-in libraries and does not require external packages to run the source code.

## Running the Application

### Run from source

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

### Run the Windows executable

The application can also be packaged into a standalone Windows executable using PyInstaller.

To generate the executable:

```bash
pip install pyinstaller
pyinstaller --onefile main.py
```

The generated executable will be located in the `dist/` directory.

Keep the four CSV files alongside the executable when running the packaged version.

## Data Storage

All records are stored locally in four CSV files:

| File | Stored information |
|---|---|
| `guitar.csv` | Guitar practice records |
| `debate.csv` | Debate practice records |
| `circuit.csv` | Circuit training records |
| `run.csv` | Running records |

The CSV files use predefined column headers and store entries between application sessions.
